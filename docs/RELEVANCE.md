# 관련도 재설계 — "나와 관련된 것만"

> 2026-10-25 시작. 진행은 [`ROADMAP.md`](ROADMAP.md)에 체크. 평가셋·스크립트는 `tests/relevance/`.

## 왜

9개 상황(동탄 맞벌이 부모, 해운대 카페, 마포 전세 1인 가구, 김제 농민, 수성구 2주택자, 인천 물류 대표, 제주 펜션, 춘천 발달장애 아동 부모, 부업 IT 개발자)을 실제 서비스에 넣고, 후보 598건을 **따로 판정**(꼭 관련 2 · 관련될 수도 1 · 무관 0)했다.

| 기준선 (2026-10-25) | 값 |
|---|---|
| 타임라인 본문에 보인 것 | 226건 |
| 그중 관련(≥1) | **27%** (꼭 관련 8%) |
| 꼭 관련 잡음 | 19/20 |
| 관련(≥1) 잡음 | 62/90 (69%) |

빠뜨리지는 않지만 **보이는 것의 4분의 3이 무관**하다. 원인:

1. **관심 낱말 하나만 맞아도 '분명히 관련'** — '정보통신'→정보통신**공사업**, '주거'→외국인 근로자 숙소, '화재'→공동주택 화재 보강
2. **분야가 너무 굵음** — 화면엔 '양도소득세·다주택 과세'라고 보이지만 실제 비교는 '부동산 세금' 전체 → 분양가상한제 건축비·임시 조립주택 지침까지
3. **지켜보는 법령의 모든 변경** — 소득세법을 지켜보면 청년 세입자에게도 '일시적 2주택'
4. **우리 동네 조례 전부** — 의회 국외출장·위원회 운영 같은 행정 내부가 절반

## 어떻게: 같은 꼬리표로 양쪽을 맞춘다

```
변경 ──(AI, 정리 단계)──▶ 대상 꼬리표 aud + 행동 종류 act ─┐
                                                          ├─▶ 겹치면 '내 타임라인'
사용자 상황 글 ──(AI, /profile)──▶ 대상 꼬리표 aud ────────┘
```

- **꼬리표 목록** `config/audience.json` — 66개. 가구·생애(영유아 부모, 장애인·가족…), 집·땅(세입자, 다주택자…), 일(직장인, 프리랜서·부업…), 사업 공통(소상공인, 고용주…), 업종(음식점·카페, 숙박업, 농업…), 누구나(국민 누구나, 지역 주민 누구나).
- **행동 종류** 7개 — 받을 것 · 해야 할 것 · 하면 안 되는 것 · 계산이 바뀌는 것 · 절차가 바뀌는 것 · 권리가 바뀌는 것 · 행정 내부. '그다음' 기능(할 일 카드·기한 알림)의 재료이기도 함.
- **꼬리표 붙이기** `lcf/tag.py` — 쉬운 말 요약이 있으면 그것(짧고 정확), 없으면 원문 앞부분을 입력. Haiku, 요청 하나에 10건, 과거분은 배치(반값). `it["tags"]`에 따로 저장해서 쉬운 말과 독립.
- **조건** — Worker `/profile`이 같은 목록에서 `aud`(전체)와 분야별 `aud`를 고름. 조건 화면에서 사용자가 고칠 수 있음('이런 분께 닿는 변화를 골라요'). 예전 조건은 처음 입력한 상황 글로 한 번 다시 만들어 꼬리표만 더함.

- Claude 5.x는 생각(thinking)이 기본으로 켜져 있고 `max_tokens`에 들어감. Haiku에 생각을 끄면(`disabled`) 꼬리표가 비거나 엉뚱해짐 — 빠른 대신 품질이 크게 떨어짐. Sonnet 5.5는 `disabled`를 거부해서 `between_tools`(도구가 없으니 사실상 끔).
- 규칙 다듬기: (1) 할 일(act)이 없는 변경은 접힌 칸, (2) 넓은 꼬리표(직장인·소상공인·중소기업·고용주·법인·학생·청소년·청년·노인·1인 가구·학부모)만 겹치면 변경이 그 무리를 콕 집고(꼬리표 2개 이하) 실제 할 일이 있을 때만 본문. 빠진 것은 '그 밖에' 접힌 칸에 남음.
- 같은 판정자·같은 9명으로 다듬었으므로 과적합 가능성 있음 → 관심 있음/없음 집계로 계속 확인.

### 2차 판정 — 실제로 보이는 것 전부 (같은 판정자, +295건)

1차 평가셋은 **예전 규칙이 고른 후보**에서 뽑았다. 새 규칙이 새로 보여 준 항목은 판정에 없어서 정밀도가 부풀었다. 새로 보인 295건을 같은 기준으로 더 판정해 합쳤다(`gold2.json`).

| 규칙 | 보임 | 정밀도 | 꼭 관련 재현 | 관련 재현 |
|---|---|---|---|---|
| 예전 규칙 | 225 | 27% | 18/23 | 43% |
| 꼬리표 + '넓은 꼬리표도 콕 집으면 허용' | 392 | 30% | 23/23 | 83% |

→ 꼬리표는 **놓치지 않는 데는 강하지만 거르기엔 거칠다**. 다음: 꼬리표로 넓게 모은 후보를 AI가 그 사람의 상황 글 기준으로 한 번 더 판정(판정자와 같은 일).
